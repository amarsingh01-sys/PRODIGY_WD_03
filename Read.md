# ❌⭕ Tic Tac Toe Game  
**Prodigy InfoTech – Web Development Internship (Project 3)**

## 📖 About the Project  
This project is a **Tic Tac Toe Game** developed as part of **Prodigy InfoTech Web Development Internship – Project 3**.  
The game allows two players to play turn by turn on the same device with a simple and interactive user interface.

---

## ✨ Features  
- Two-player game (Player X vs Player O)  
- Interactive game board  
- Win detection logic  
- Draw detection  
- Restart / Reset game option  
- Clean and responsive UI  

---

## 🛠️ Technologies Used  
- **HTML5** – Game structure  
- **CSS3** – Styling and layout  
- **JavaScript** – Game logic and interactivity  

---

## 📁 Project Structure  
├── index.html
├── style.css
├── script.js
└── README.md


---

## ▶️ How to Run the Project  
1. Download or clone the repository  
2. Open `index.html` in any modern web browser  
3. Start playing the Tic Tac Toe game
